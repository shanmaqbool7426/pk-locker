The root is a Gradle-managed Android project with `settings.gradle.kts` declaring the single included module `:app`; the sibling `data/` directory holds a standalone Kotlin file (`ApiService.kt`) that mirrors the network models used by the app's `data` package, acting as an out-of-tree reference implementation or server-side counterpart rather than a compiled Gradle module. The top-level `build.gradle.kts` applies only plugin declarations via `alias(libs.plugins.*) apply false`, while actual dependency versions are centralized in `gradle/libs.versions.toml`. Cross-cutting concerns—Firebase configuration (`google-services.json`), keystore files (`prod.keystore`, `release*.keystore`), and provisioning/debug artifacts (`setup_device_owner.bat`, `provisioning_debug.log`, `test_dl*.apk`)—live at the root so they can be referenced uniformly by the app module during build and release flows.
