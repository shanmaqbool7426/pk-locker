Single-namespace Android app (`com.pksafe.lock.manager`) built with Kotlin + Jetpack Compose (Material3) and a traditional `ComponentActivity` entry point in `MainActivity.kt`. The UI is organized by feature under `ui/` (dashboard, devices, login/signup, registration, provisioning, keys, deregister, emi, profile), each pairing a Screen composable with a ViewModel. System-level enforcement lives outside the UI: `service/LockService` runs as a foreground service to draw the lock overlay; `service/AntiUninstallService` is an `AccessibilityService` that intercepts Settings/uninstaller intents and blocks uninstallation or factory reset; `receiver/AdminReceiver` handles Device Admin lifecycle and auto-grants permissions on provisioning completion; additional receivers (`BootReceiver`, `SimStateReceiver`, `SmsReceiver`) react to system events. `util/LockManager` centralizes all Device Policy Manager calls (camera disable, USB/file transfer/blocking, safe mode, ADB debugging, status bar, keyguard). Network layer is a single Retrofit interface `data/ApiService.kt` plus data models in `data/Models.kt`, used from both `MainActivity` (customer token sync, IMEI fetch) and feature ViewModels. Background work uses WorkManager (`worker/LocationWorker`, `service/ConnectivityWorker`). Provisioning flows are split across QR/NFC/ADB/cable/wireless screens under `ui/provisioning`. Persistence is SharedPrefs (`PKLockerPrefs`) plus local files served through a `FileProvider`. Build configuration signs debug/release with the same keystore, enables V1/V2/V3 signing for Play Protect compatibility, and targets SDK 35 with minSdk 24.
