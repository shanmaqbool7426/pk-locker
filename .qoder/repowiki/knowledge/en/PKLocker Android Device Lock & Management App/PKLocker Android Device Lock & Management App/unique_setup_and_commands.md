Build uses a shared release keystore (`prod.keystore`) for both debug and release so Play Protect treats debug builds identically; V1/V2/V3 signing schemes are explicitly enabled. A Gradle task hook deletes a corrupted `app_icon_professional.png` before resource merging. The app requires explicit user enrollment as Device Owner (via QR/ADB provisioning) to unlock full restrictions; without it, many DPM features fall back gracefully.
